NextPlay Gaming Guide

Website Project Site Plan

Site Name

NextPlay Gaming Guide

NextPlay Gaming Guide is a website designed to help users discover video games based on genre, platform, and rating. The name NextPlay was chosen because the website helps users decide which game they may want to play next.

Logo: A game controller represents the gaming focus of the website.

Optional Domain: nextplayguide.com

Site Purpose

The purpose of NextPlay Gaming Guide is to help users discover video games based on their interests. The website will provide information about games including their genre, platform, and rating.

Users will be able to browse games, filter the game list, view recommendations, and save games they would like to play later.

Scenarios

  • What games are available for my preferred platform and genre?
  • Which games have the highest ratings and are recommended to play?
  • How can I save a game so I can remember to play it later?

Wireframes

Desktop View

The desktop layout includes a navigation header, hero area, featured game cards, a section explaining the site's main features, and a footer.

Mobile View

The mobile layout displays the same information in a vertical format. Featured games are stacked and the navigation is replaced with a hamburger menu.
